# ULTRAI

Claude Desktop 스타일 AI 채팅 데스크톱 앱.

> 이 저장소는 **릴리스 배포 전용**입니다. 소스 코드는 여기에 공개되지 않습니다.
> 최신 설치본은 [Releases](https://github.com/UltraK18/ULTRAI/releases/latest) 에서 받을 수 있습니다.

## 설치

[Releases](https://github.com/UltraK18/ULTRAI/releases/latest) 에서 최신 `ULTRAI_x.y.z_x64_en-US.msi` 를 내려받아 실행하세요.

앱 안에서도 시작 시·주기적으로 새 버전을 확인하며, 새 버전이 있으면 알림에서 바로 내려받아 설치할 수 있습니다.
