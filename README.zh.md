# ULTRAI

一款持续运行的 Windows 桌面 AI 工作应用。单一窗口内集成四种模式——对话、在真实项目文件夹中构建、在画布上设计、生成图像与视频——并支持任务调度、多智能体协作,以及将手机作为第二屏幕。

## 下载

支持 Windows 10 / 11(x64)。需要 WebView2 运行时,该组件在大多数 Windows 安装中已预置。

**[下载最新版本](https://github.com/UltraK18/ULTRAI/releases/latest)**——获取 `ULTRAI_x.y.z_x64_en-US.msi` 并运行。

之后应用会自行处理更新:启动时及运行期间会定期检查新版本,发现可用更新时会提示你,并原地完成安装。

## 四种模式,一个窗口

每种模式都是为特定用途打造的独立界面,拥有各自的工具和智能体——但始终是同一个应用、同一套设置、同一处保存历史记录的地方。

| 模式 | 界面 | 你能做什么 |
| :--- | :--- | :--- |
| **Chat** | 对话 | 任意服务商与模型,按消息设置推理强度,含引用的深度研究,支持文件与图片输入 |
| **Code** | 真实项目文件夹 | 文件树、审阅面板中的差异对比、聊天旁的终端、任何改动落盘前的权限确认 |
| **Design** | 实时画布 + 设计师智能体 | 界面在构建过程中实时渲染于聊天旁;完成后的成果以真实文件形式交给 Code |
| **Studio** | 自由画布 + 聊天 | 生成图像与视频,放置并重新排列,拖入自己的文件,持续在现有内容上迭代 |

切换模式不会重启任何东西——每种模式各自保留自己的对话,侧边栏只显示当前所在模式下的对话。

## 界面本身就是重点

这一领域的多数工具本质上是终端或套壳网页。ULTRAI 是一款经过设计、而非拼装而成的桌面应用。

- **真正的玻璃质感**——悬浮表面运行的是一套小型渲染引擎,而非模糊滤镜。它为边框烘焙法线贴图并据此绘制高光,同时对表面下方的内容进行位移,使边缘产生折射效果。开关和滑块等控件更进一步,基于折射率与厚度求解斯涅耳折射,让滑块能够弯曲其下方的轨道。CSS 的毛玻璃效果做不到这一点,差异体现在每一处边缘上。
- **超椭圆圆角**——面板采用超椭圆(squircle)而非圆弧,曲线过渡到直边时不会出现 `border-radius` 那种生硬的平直段。
- **两套主题,皆经推敲**——明暗主题基于同一套带微冷色调的混凝土灰色板,经过调校,两端都不会显得刺眼。每个界面元素都对应一个设计令牌(token),因此整个应用统一联动,不会因界面不同而各自漂移。
- **刻意的克制**——产品中不使用任何表情符号,不使用感叹号,不做夸张的宣传。每个面板只承载单一表面,层次感来自边缘光与阴影,而非层层嵌套的方框。
- **无缝窗口**——32 像素高的标题栏采用 Windows 11 规格,与应用背景同色,因此窗口外框不会显得像是内容上方独立的一条装饰。
- **移动端是不同的布局,而非缩小版**——底部弹出面板、全宽控件、适合触控的点击区域,由设备类型而非窗口宽度决定。

## 基于真实模型的生成能力

Studio 并非单一的图像生成接口。它会针对每个任务从模型目录中选取,并告诉你使用了哪个模型、原因是什么。

- **视频**——Veo 3.1 与 Veo 3.0(及其快速版本)、Sora 2 与 Sora 2 Pro、Grok Imagine Video、Gemini Omni Flash
- **图像**——GPT Image 2 与 1.5、Gemini 3 Pro Image、Gemini 3.1 Flash Image(及 Flash Lite)、Grok Imagine Image
- **视频输入,视频输出**——可将已有片段作为输入,而不仅限于文字提示
- **自我核查生成结果**——从生成内容中回抽帧画面进行查看,并据此判断是否需要重新生成
- **时长、宽高比与画质由你决定**——要求 30 秒,就会生成 30 秒,并且是你要求的画幅

能够使用哪些模型,取决于你连接的服务商账号(Vertex AI、OpenAI、xAI)。

## ULTRA 模式——多智能体协作完成一项任务

适用于单个上下文容纳不下的大型任务。ULTRA 会将任务拆分为多个子任务,分阶段调度多个智能体执行,并在结果合并前进行**独立验证**——由评审者与对抗性检查完成,而非同一个智能体自我评分。你可以全程观察运行过程,并随时介入。模型与推理强度按角色分别设置,因此可以刻意让低成本的执行者与高成本的验证者来自不同的服务商。

## 它会准时赴约

说一句“每个工作日 9 点”或“两小时后”,它就会变成一项真正的任务,而不只是一条备忘。任务触发时,会作为该对话中的一轮消息到达,AI 随即开始处理。

- 日历与列表展示所有已登记的任务;下一次运行时间显示在侧边栏底部
- 任务到期时应用未开启?它会计算错过的内容,合并为一次补做运行
- `/loop` 会按你设定的轮数重复执行任务

## AI 无法自行宣布完成的目标

为一段对话设定目标后,完成与否由独立评估把关。执行任务的智能体本身无权判定任务已经完成。

## 深入挖掘的研究,以及动手前的提问

**深度研究**会先规划切入角度,再由多个子智能体并行搜索与阅读,并为找到的内容标注引用。日常搜索的要求同样严格:模型被要求进行搜索而非凭空猜测,使用当前日期而非训练数据中残留的年份,并在给出现在时态的结论前进行核实。研究结果以客观公允的方式呈现,来源以内联形式标注。

**深度访谈**——当请求描述不够明确时,它会将对话转为结构化访谈,在动手之前先确认你的真实需求。

## 在你做其他事情时持续运行的任务

耗时较长的任务不会占用窗口、阻塞其他操作。

- **后台运行**——将任务交出后,它会以对话分支或子智能体的形式隔离运行,遇到阻碍时可在运行途中申请更多权限。
- **实时监控栏**——底部的状态栏同时展示所有进行中的任务:你自己发起的后台任务、其他地方启动的任务、正在运行的子智能体调用、ULTRA 运行,以及运行时间较长的任何 shell 命令。点击即可跳转查看任意一项。
- **分支对话**——可从任意节点分出新分支进行尝试而不影响原对话,并可通过消息索引在各分支间跳转。

## 模式之间的任务交接

工作不会被困在最初发起的模式中。Design 会将完成的界面以真实文件的形式交给 Code。Code 会话之间可以互相传递问题与结果。Studio 会将智能体生成的内容直接放置到画布上。每一次交接传递的都是真实的文件或真实的对话轮次,而不是复制粘贴的文本块。

## 一个 AI 可以自由使用、又不会触碰你文件的工作空间

Chat 模式拥有自己独立的磁盘暂存空间。AI 可以在其中自由写入、读取、运行与修改内容——草稿、脚本、中间文件——无需每一步都征求你的许可,也不会涉足你的文件夹。你完全不必关心它在哪里,只需要拿到结果;除非你主动指向自己的目录,否则它们始终不会被触碰。

## 会话之间可以互相通信

在 Code 模式中,一个会话可以将问题或结果传递给另一个会话——负责后端的会话可以向了解前端的会话提问。消息会作为真实的一轮对话到达对方会话。通道由你手动开启,不会自动连接。

## 你的手机就是第二块屏幕

开启服务后,在同一网络下的手机浏览器中打开 ULTRAI 即可使用。移动端布局专为触控设计——底部弹出面板、全宽控件——而非桌面版的缩小版本。对话、模型与设置均为共享,可以从中断的地方继续。

## 让它成为你的专属工具

以下每一项都是磁盘上的一份普通文件,你可以读取、编辑并进行版本管理。

- **智能体(Agents)**——`~/.ultrai/agents/*.md`。文件头部的 frontmatter 决定一切:该智能体出现在哪些模式中、可使用哪些工具、获得哪些提示词片段、被允许使用哪些功能(研究、目标、访谈)。可在设置中编辑,内置智能体可随时恢复为初始状态。
- **技能(Skills)**——`~/.ultrai/skills/*/SKILL.md`。模型可调用的可复用指令,你也可以通过斜杠命令直接调用。每项技能均可单独开关。
- **提示词模块(Prompt modules)**——系统提示词由一套模块目录组装而成,每个智能体的 frontmatter 决定获取哪些片段。不声明任何内容时,智能体的提示词与默认版本逐字节相同;主动选用则可改变其思考方式。每种模式都配有针对该类工作单独构建的提示词,而非用一套提示词硬套所有场景。
- **MCP 服务器**——在 `ultrai.jsonc` 中声明。可本地可远程,按需配置认证,并可逐个服务器单独开关。
- **记忆(Memory)**——分为三类存放(关于你、主题、领域),摘要会被自动注入,细节按需取用,并定期执行清理以合并重复与冲突的内容。仅限 Chat 模式使用,所有条目均可在设置中查看与删除。
- **服务商(Providers)**——支持 Anthropic、OpenAI、Google、Google Vertex、xAI、OpenRouter 及自定义端点,使用你自己的密钥。

## 你的数据只保存在你的电脑上

对话与设置**仅**存储在你自己的设备上。不存在 ULTRAI 服务器——你的对话只会发送给你自己连接的 AI 服务商,并使用你自己的密钥。

不收集任何数据,不含遥测。

## 快速开始

1. **连接服务商**——在“设置 → Providers”中添加你的 API 密钥。
2. **选择模型**——模型与推理强度位于输入框右侧。
3. **选择模式**——位于侧边栏顶部的标签页。
4. **开始工作**——在 Code 模式下打开一个文件夹;其他模式下直接开始对话即可。
5. **交办任务**——说一句“每晚帮我总结当天的情况”,它会自行接手执行。

## 技术栈

一款基于 Tauri 2 构建的原生 Windows 应用。界面使用 SolidJS 构建;后端以单一二进制文件的形式随应用一同打包。
