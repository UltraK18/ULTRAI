## Download

Windows 10 / 11 (x64) ต้องมี WebView2 runtime ซึ่งมีอยู่แล้วในเครื่อง Windows ส่วนใหญ่

**[ดาวน์โหลดรุ่นล่าสุด](https://github.com/UltraK18/ULTRAI/releases/latest)** — ดาวน์โหลดไฟล์ `ULTRAI_x.y.z_x64_en-US.msi` แล้วรันได้เลย

หลังจากนั้นแอปจะดูแลตัวเอง โดยจะตรวจสอบเวอร์ชันใหม่ทุกครั้งที่เปิดและเป็นระยะ แจ้งเตือนเมื่อมีอัปเดต และติดตั้งให้ทันทีในที่เดิม

## Four modes, one window

แต่ละโหมดคือหน้าจอที่ออกแบบมาเฉพาะทาง มีเครื่องมือและเอเจนต์เป็นของตัวเอง — แต่รวมอยู่ในแอปเดียว ตั้งค่าชุดเดียว และประวัติการใช้งานทั้งหมดอยู่ที่เดียวกัน

| Mode | หน้าจอ | สิ่งที่คุณทำที่นั่น |
| :--- | :--- | :--- |
| **Chat** | บทสนทนา | โพรวายเดอร์และโมเดลใดก็ได้ ปรับ reasoning effort ต่อข้อความ ทำ deep research พร้อมการอ้างอิงแหล่งที่มา แนบไฟล์และรูปภาพเข้ามาได้ |
| **Code** | โฟลเดอร์โปรเจกต์จริง | โครงสร้างไฟล์ ดู diff ในพาเนลตรวจทาน มีเทอร์มินัลอยู่ข้างแชท และมีข้อความขอสิทธิ์ก่อนที่จะแตะไฟล์ใด ๆ |
| **Design** | แคนวาสสด + เอเจนต์นักออกแบบ | หน้าจอต่าง ๆ จะเรนเดอร์ขึ้นข้างแชทระหว่างสร้าง งานที่เสร็จแล้วจะส่งต่อไปยัง Code เป็นไฟล์จริง |
| **Studio** | แคนวาสอิสระ + แชท | สร้างภาพและวิดีโอ จัดวางและสลับตำแหน่งได้ ลากไฟล์ของคุณเองเข้ามา และปรับแก้งานที่มีอยู่ต่อไปได้เรื่อย ๆ |

การสลับโหมดไม่ทำให้อะไรรีสตาร์ท — แต่ละโหมดเก็บบทสนทนาของตัวเองไว้ต่างหาก และแถบด้านข้างจะแสดงเฉพาะบทสนทนาที่อยู่ในโหมดที่คุณกำลังใช้งาน

## The interface is the point

เครื่องมือส่วนใหญ่ในสายนี้ก็คือเทอร์มินัลหรือหน้าเว็บที่ครอบด้วย wrapper อีกที ส่วน ULTRAI เป็นแอปเดสก์ท็อปที่ถูก
"ออกแบบ" ไม่ใช่แค่ "ประกอบ" ขึ้นมา

- **กระจกที่เป็นกระจกจริง** — พื้นผิวลอยตัวทำงานด้วยเรนเดอร์เอนจินขนาดเล็ก ไม่ใช่ฟิลเตอร์เบลอ มันเบค normal map
  สำหรับขอบเบเซล วาด specular highlight จากค่านั้น และบิดเบือนสิ่งที่อยู่ด้านหลังพื้นผิวให้เกิดการหักเหที่ขอบ
  ส่วนควบคุมอย่างสวิตช์และสไลเดอร์ไปไกลกว่านั้นอีก โดยคำนวณการหักเหแบบ Snell ด้วยค่าดัชนีหักเหและความหนาจริง
  ทำให้ปุ่มเลื่อนบิดโค้งแทร็กที่อยู่ใต้มัน ฟิลเตอร์ frost แบบ CSS ทำแบบนี้ไม่ได้ และความต่างก็เห็นได้ในทุกขอบ
- **มุมแบบ Squircle** — พาเนลใช้เส้นโค้งซูเปอร์เอลลิปส์ ไม่ใช่ส่วนโค้งวงกลม ทำให้เส้นโค้งเชื่อมเข้ากับขอบตรงโดยไม่มี
  จุดแบนแบบที่เกิดจาก `border-radius`
- **สองธีมที่ตั้งใจออกแบบทั้งคู่** — ธีมสว่างและธีมมืดสร้างจากชุดสีโทนปูนที่มีเฉดเย็นบาง ๆ ปรับแต่งให้ไม่มีจุดไหน
  จ้าเกินไปทั้งสองด้าน ทุกพื้นผิวผูกกับ token เดียวกัน แอปทั้งหมดจึงเปลี่ยนไปพร้อมกัน ไม่เพี้ยนไปทีละหน้าจอ
- **ความเรียบง่ายที่ตั้งใจ** — ไม่มีอิโมจิที่ใดในผลิตภัณฑ์ ไม่มีเครื่องหมายตกใจ ไม่มีถ้อยคำเชียร์เกินจริง แต่ละพาเนล
  มีพื้นผิวเดียว การแบ่งแยกมาจากแสงขอบและเงา ไม่ใช่กล่องซ้อนกล่อง
- **หน้าต่างไร้รอยต่อ** — แถบชื่อหน้าต่างสูง 32px ตามมาตรฐาน Windows 11 ใช้พื้นหลังเดียวกับตัวแอป ทำให้ chrome
  ไม่ดูเหมือนแถบแยกที่ลอยอยู่เหนือเนื้อหา
- **มือถือมีเลย์เอาต์ที่ต่างออกไป ไม่ใช่แค่ย่อขนาดลง** — bottom sheet ปุ่มควบคุมเต็มความกว้าง และพื้นที่สัมผัส
  ขนาดเหมาะกับนิ้ว ตัดสินใจจากอุปกรณ์ ไม่ใช่จากความกว้างหน้าต่าง

## Generation, with real models

Studio ไม่ใช่ endpoint สร้างภาพตัวเดียว แต่เลือกจากแคตตาล็อกโมเดลตามงานแต่ละชิ้น และบอกคุณว่าใช้โมเดลไหนและเพราะอะไร

- **วิดีโอ** — Veo 3.1 และ Veo 3.0 (รวมถึงรุ่น fast) Sora 2 และ Sora 2 Pro, Grok Imagine Video, Gemini Omni Flash
- **ภาพ** — GPT Image 2 และ 1.5, Gemini 3 Pro Image, Gemini 3.1 Flash Image (และ Flash Lite), Grok Imagine Image
- **ใส่วิดีโอเข้า ได้วิดีโอออก** — ป้อนคลิปที่มีอยู่แล้วเป็นอินพุตได้ ไม่ใช่แค่ข้อความสั่ง
- **ตรวจงานของตัวเอง** — ดึงเฟรมออกมาจากสิ่งที่สร้างขึ้น ตรวจดู แล้วตัดสินใจว่าควรลองใหม่หรือไม่
- **ความยาว อัตราส่วนภาพ และคุณภาพเป็นไปตามที่คุณกำหนด** — ขอ 30 วินาที ก็ได้ 30 วินาทีตามที่ขอ ในรูปแบบที่คุณต้องการ

โมเดลที่คุณใช้ได้ขึ้นอยู่กับบัญชีโพรวายเดอร์ที่คุณเชื่อมต่อ (Vertex AI, OpenAI, xAI)

## ULTRA mode — many agents, one job

สำหรับงานที่ใหญ่เกินกว่าจะใส่ใน context เดียว ULTRA จะแบ่งงานออกเป็นทาสก์ รันข้ามเอเจนต์ทีละเฟส และให้ผลลัพธ์
**ถูกตรวจสอบโดยอิสระก่อนจะรวมเข้าด้วยกัน** — ผ่านตัววิจารณ์และการตรวจสอบเชิงปฏิปักษ์ ไม่ใช่ให้เอเจนต์ตัวเดียวกัน
ให้คะแนนงานตัวเอง คุณสามารถดูการรันและเข้าแทรกแซงได้ทุกจุด โมเดลและ reasoning effort ตั้งค่าแยกตามบทบาท
ทำให้ตั้งใจใช้ worker ราคาถูกและ verifier ราคาแพงจากคนละโพรวายเดอร์ได้

## It keeps its appointments

พูดว่า "ทุกวันธรรมดา 9 โมง" หรือ "อีกสองชั่วโมง" มันจะกลายเป็นงานจริง ไม่ใช่แค่บันทึกไว้เฉย ๆ เมื่อถึงเวลา ทาสก์นั้น
จะปรากฏเป็นเทิร์นในบทสนทนานั้น แล้ว AI ก็เริ่มลงมือทำทันที

- ปฏิทินและรายการแสดงทุกอย่างที่ลงทะเบียนไว้ การรันครั้งถัดไปจะอยู่ด้านล่างของแถบด้านข้าง
- ปิดแอปอยู่ตอนถึงเวลาที่กำหนดใช่ไหม มันจะคำนวณว่าพลาดอะไรไปบ้างแล้วรวมเข้าเป็นการรันไล่ตามครั้งเดียว
- `/loop` ทำซ้ำทาสก์ตามจำนวนรอบที่คุณกำหนด

## Goals the AI cannot declare done

ตั้งเป้าหมายให้กับบทสนทนา แล้วการประเมินอย่างอิสระจะเป็นตัวตัดสินความสำเร็จ เอเจนต์ที่ลงมือทำงานเองไม่มีสิทธิ์
ตัดสินว่างานเสร็จแล้ว

## Research that digs, and questions before work

**Deep research** วางแผนมุมมองต่าง ๆ ก่อน แล้วค้นหาและอ่านแบบขนานผ่านซับเอเจนต์หลายตัว พร้อมอ้างอิงแหล่งที่มา
ของสิ่งที่พบ การค้นหาทั่วไปก็เข้มงวดผิดปกติเช่นกัน โมเดลถูกกำหนดให้ค้นหาแทนการเดา ใช้วันที่ปัจจุบันแทนปีที่ติดมา
จากข้อมูลฝึกฝน และตรวจสอบข้อความอ้างเชิงปัจจุบันก่อนตอบ ผลการค้นพบนำเสนออย่างเป็นกลาง พร้อมแหล่งอ้างอิงแทรก
ในเนื้อหา

**Deep interview** — เมื่อคำขอยังไม่ชัดเจนพอ มันจะเปลี่ยนบทสนทนาให้กลายเป็นการสัมภาษณ์แบบมีโครงสร้าง เพื่อระบุ
ให้ชัดว่าคุณต้องการอะไรจริง ๆ ก่อนเริ่มลงมือทำงาน

## Work that runs while you do something else

งานที่ใช้เวลานานจะไม่ยึดหน้าต่างไว้ทั้งหมด

- **การรันเบื้องหลัง** — ส่งมอบทาสก์ไปแล้วมันจะรันแยกต่างหาก ไม่ว่าจะเป็น fork ของบทสนทนาหรือซับเอเจนต์ และ
  สามารถขอสิทธิ์เพิ่มเติมระหว่างรันได้หากติดขัด
- **มอนิเตอร์แบบสด** — แถบด้านล่างแสดงทุกอย่างที่กำลังทำงานพร้อมกัน ทั้งทาสก์เบื้องหลังของคุณเอง งานที่เริ่มจาก
  ที่อื่น การเรียกซับเอเจนต์ที่กำลังทำงาน การรัน ULTRA และคำสั่ง shell ใด ๆ ที่ทำงานมาสักพัก คลิกเข้าไปดูตัวไหน
  ก็ได้ที่ต้องการติดตาม
- **Fork บทสนทนา** — แตกกิ่งจากจุดใดก็ได้เพื่อลองสิ่งใหม่โดยไม่เสียของเดิม และสลับไปมาระหว่างกิ่งต่าง ๆ ได้จาก
  ดัชนีข้อความ

## Handoff between modes

งานจะไม่ค้างอยู่ในโหมดที่เริ่มต้นไว้ Design ส่งต่อหน้าจอที่เสร็จแล้วไปยัง Code เป็นไฟล์จริงบนดิสก์ เซสชัน Code
ส่งคำถามและผลลัพธ์ถึงกันได้ Studio วางสิ่งที่เอเจนต์สร้างขึ้นลงบนแคนวาสโดยตรง การส่งต่อแต่ละครั้งย้ายไฟล์จริง
หรือเทิร์นจริง ไม่ใช่แค่ก้อนข้อความที่คัดลอกมา

## A workspace the AI can use without touching your files

โหมด Chat มีพื้นที่ scratch เป็นของตัวเองบนดิสก์ AI สามารถเขียน อ่าน รัน และแก้ไขสิ่งต่าง ๆ ในนั้นได้อย่างอิสระ
ไม่ว่าจะเป็นฉบับร่าง สคริปต์ หรือไฟล์ระหว่างทาง โดยไม่ต้องขอสิทธิ์คุณทุกขั้นตอนและไม่แตะโฟลเดอร์ของคุณ คุณไม่ต้อง
คิดเลยว่าพื้นที่นั้นอยู่ที่ไหน แค่รอรับผลลัพธ์ ส่วนไดเรกทอรีของคุณเองจะไม่ถูกแตะต้อง เว้นแต่คุณจะชี้ให้มันไปที่นั่น

## Sessions that talk to each other

ในโหมด Code เซสชันหนึ่งสามารถส่งคำถามหรือผลลัพธ์ให้อีกเซสชันหนึ่งได้ — เซสชันที่ทำงานฝั่ง backend สามารถถาม
เซสชันที่รู้เรื่อง frontend ได้ ข้อความจะมาถึงเป็นเทิร์นจริงในอีกบทสนทนาหนึ่ง คุณเป็นคนเปิดช่องทางเอง ไม่มีอะไร
เชื่อมต่อกันเองโดยอัตโนมัติ

## Your phone is a second screen

เปิดเซิร์ฟเวอร์แล้วเข้าถึง ULTRAI จากเบราว์เซอร์บนโทรศัพท์ในเครือข่ายเดียวกัน เลย์เอาต์บนมือถือถูกออกแบบมาเพื่อ
การสัมผัสโดยเฉพาะ — bottom sheet และปุ่มควบคุมเต็มความกว้าง — ไม่ใช่เดสก์ท็อปที่ย่อลงมา บทสนทนา โมเดล และ
การตั้งค่าจะแชร์ร่วมกัน คุณจึงทำงานต่อได้จากจุดเดิมพอดี

## Make it yours

ทุกอย่างด้านล่างนี้คือไฟล์ธรรมดาบนดิสก์ของคุณ ที่คุณสามารถอ่าน แก้ไข และควบคุมเวอร์ชันได้เอง

- **Agents** — `~/.ultrai/agents/*.md` frontmatter เป็นตัวกำหนดทุกอย่าง ปรากฏในโหมดไหน ใช้เครื่องมือใดได้บ้าง
  ได้รับส่วนพรอมต์ใด และได้รับอนุญาตให้ใช้ฟีเจอร์ใด (research, goals, interview) แก้ไขได้จาก Settings และ
  เอเจนต์ที่มาพร้อมแอปสามารถคืนค่ากลับต้นฉบับได้ทุกเมื่อ
- **Skills** — `~/.ultrai/skills/*/SKILL.md` คำสั่งที่นำกลับมาใช้ซ้ำได้ ซึ่งโมเดลสามารถดึงมาใช้เอง หรือคุณจะ
  เรียกใช้ผ่าน slash command ก็ได้ เปิดปิดได้แต่ละตัว
- **Prompt modules** — system prompt ถูกประกอบขึ้นจากแคตตาล็อก และ frontmatter ของแต่ละเอเจนต์เลือกว่าจะ
  ได้ส่วนไหนไปบ้าง ถ้าไม่ประกาศอะไรเลย พรอมต์ของเอเจนต์จะเหมือนกับค่าเริ่มต้นทุกไบต์ เลือกเปิดใช้เพื่อเปลี่ยน
  วิธีคิดของมัน แต่ละโหมดมาพร้อมพรอมต์ของตัวเองที่สร้างมาสำหรับงานประเภทนั้นโดยเฉพาะ แทนที่จะใช้พรอมต์เดียว
  ดัดให้เข้ากับทุกอย่าง
- **MCP servers** — ประกาศไว้ใน `ultrai.jsonc` จะเป็นแบบโลคัลหรือรีโมตก็ได้ พร้อมระบบยืนยันตัวตนเมื่อจำเป็น
  สลับเปิดปิดได้ทีละเซิร์ฟเวอร์
- **Memory** — เก็บไว้ในสามหมวด (เกี่ยวกับคุณ หัวข้อ พื้นที่) สรุปจะถูกแทรกเข้าไป ส่วนรายละเอียดจะดึงมาเมื่อจำเป็น
  พร้อมกระบวนการล้างข้อมูลเป็นระยะที่รวมรายการซ้ำและข้อมูลขัดแย้งกันเข้าด้วยกัน ใช้ได้เฉพาะโหมด Chat และคุณ
  สามารถดูและลบแต่ละรายการได้จาก Settings
- **Providers** — Anthropic, OpenAI, Google, Google Vertex, xAI, OpenRouter และ endpoint กำหนดเอง โดยใช้
  คีย์ของคุณเอง

## Your data stays on your PC

บทสนทนาและการตั้งค่าจัดเก็บไว้ **บนเครื่องของคุณเท่านั้น** ไม่มีเซิร์ฟเวอร์ ULTRAI — บทสนทนาของคุณจะส่งไปยัง
โพรวายเดอร์ AI ที่คุณเชื่อมต่อเองเท่านั้น โดยใช้คีย์ของคุณเอง

ไม่มีการเก็บข้อมูลใด ๆ และไม่มีการส่งข้อมูลการใช้งาน (telemetry)

## Quick Start

1. **เชื่อมต่อโพรวายเดอร์** — เพิ่ม API key ของคุณที่ Settings → Providers
2. **เลือกโมเดล** — โมเดลและ reasoning effort อยู่ทางด้านขวาของแถบป้อนข้อความ
3. **เลือกโหมด** — แท็บที่อยู่ด้านบนของแถบด้านข้าง
4. **เริ่มทำงาน** — เปิดโฟลเดอร์ในโหมด Code ส่วนโหมดอื่น ๆ แค่เริ่มพิมพ์คุยได้เลย
5. **มอบหมายงาน** — พูดว่า "สรุปวันของฉันให้ทุกคืน" แล้วมันจะรับไปทำเองโดยอัตโนมัติ
