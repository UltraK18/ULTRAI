## 왜 ULTRAI 인가

**대화가 끝나도 작업은 끝나지 않는다.** 대부분의 AI 앱은 한 번의 질문과 한 번의 답으로 완결됩니다. ULTRAI 는 그 다음을 다룹니다 — 계속 돌아가고, 여러 에이전트로 나뉘고, 휴대폰으로 옮겨가고, 때가 되면 알아서 돌아오는 작업을.

- **네 가지 모드가 한 앱에** — 대화, 코드, 디자인, 스튜디오. 모드마다 전용 화면과 도구를 갖되 창은 하나이고 설정도 하나입니다.
- **에이전트 하나로 끝나지 않습니다** — ULTRA 모드는 큰 작업을 태스크로 쪼개 여러 에이전트에 단계별로 배분하고, 결과를 독립 검증한 뒤 합칩니다. 코드 모드에서는 세션끼리 직접 대화할 수도 있습니다.
- **약속을 지킵니다** — 예약해 두면 앱이 그 시각에 스스로 대화를 이어갑니다. 그 사이 앱이 꺼져 있었어도요.

## 무엇이 다른가

**ULTRA 모드 — 태스크 기반 다중 오케스트레이션.** 한 컨텍스트에 담기지 않는 작업을 태스크 단위로 분해해 단계별로 여러 에이전트에 배분하고, 결과를 독립 검증한 뒤 병합합니다. 진행을 지켜보다 언제든 끼어들 수 있습니다.

**세션끼리 대화합니다.** 코드 모드에서 한 세션이 다른 세션에게 질문이나 결과를 넘길 수 있습니다 — 백엔드를 만지던 세션이 프론트엔드를 아는 세션에게 물어보는 식으로. 창구를 여는 건 사용자 승인이 있어야 하며, 저절로 열리지 않습니다.

**디자인 모드 — 디자이너가 붙은 캔버스.** 살아 있는 캔버스 위에서 디자이너 에이전트와 화면을 만듭니다. 사이드바 대화로 고쳐 나가면 옆에서 결과가 바로 그려지고, 완성된 결과물은 실제 파일로 코드 모드에 넘어갑니다.

**스튜디오 모드 — 캔버스 위에서 생성.** 자유 캔버스 옆 대화로 이미지와 영상을 만들고, 배치하고, 내 파일을 끌어다 놓고, 이미 있는 것을 이어서 다듬습니다.

**휴대폰이 두 번째 화면.** 서버를 켜면 같은 네트워크의 폰 브라우저에서 ULTRAI 를 엽니다. 데스크톱을 줄인 화면이 아니라 터치를 위해 만든 전용 레이아웃이고, 세션·모델·설정을 공유하므로 하던 자리에서 그대로 이어집니다.

**예약과 반복 작업.** "평일 아침 9시에", "2시간 뒤에" 라고 말하면 실제 작업으로 등록됩니다. 발동하면 그 대화에 작업 턴이 들어오고, 달력과 목록으로 전체를 한눈에 봅니다. 다음에 울릴 예약은 사이드바 하단에 항상 떠 있습니다. 발동 시각에 앱이 꺼져 있었다면 놓친 만큼을 계산해 한 번으로 합쳐 처리합니다.

**검증받는 목표.** 대화에 목표를 걸면 독립 평가가 완료를 판정합니다 — AI 가 스스로 "다 했다"고 선언할 수 없습니다. 반복 작업은 정해둔 횟수만큼 스스로 이어집니다.

**제대로 파고드는 리서치.** 딥리서치는 실제 조사를 수행합니다 — 조사할 각도를 설계하고, 서브 에이전트로 병렬 검색·정독한 뒤, 찾은 근거를 인용해 보고합니다. 평상시 검색도 남다릅니다: 추측 대신 먼저 찾아보게 하고, 학습 시점의 연도가 아니라 오늘 날짜를 쓰게 하며, 현재형 주장은 확인한 뒤 답하게 합니다. 출처는 본문에 인라인으로 달리고, 결과는 단정 대신 균형 있게 제시됩니다.

**딥인터뷰.** 요청이 모호하면 먼저 구조화된 문답으로 바꿉니다 — 작업을 시작하기 전에 원하는 바를 확정합니다.

## 그 밖에

**코드** — 실제 프로젝트 폴더를 열어 코드베이스를 분석하고 수정합니다. 변경 사항은 검토 패널에서 diff 로 보고, 파일 트리와 터미널을 함께 씁니다.

**대화** — 여러 공급자와 모델을 자유롭게 오가고, 메시지마다 응답 강도를 바꿉니다.

**기억과 개인화** — 대화에서 알게 된 것을 기억해 다음 대화에 쓰고, 지난 대화를 검색할 수 있습니다. 에이전트를 직접 만들고, 스킬과 MCP 서버를 붙이며, 무엇을 기억할지 설정에서 관리합니다.

## 설치

Windows 10 / 11 (x64). WebView2 런타임이 필요하며, 대부분의 Windows 에는 이미 설치되어 있습니다.

[Releases](https://github.com/UltraK18/ULTRAI/releases/latest) 에서 최신 `ULTRAI_x.y.z_x64_en-US.msi` 를 내려받아 실행하세요.

앱이 시작 시와 주기적으로 새 버전을 확인하고, 새 버전이 있으면 알려준 뒤 그 자리에서 설치합니다.

## 시작하기

1. **AI 공급자 연결** — 설정 → 공급자에서 사용할 서비스의 키를 넣습니다.
2. **모델 선택** — 입력창 오른쪽에서 모델과 응답 강도를 고릅니다.
3. **모드 선택** — 사이드바 위쪽 탭에서 대화 / 코드 / 디자인 / 스튜디오를 오갑니다.
4. **작업 시작** — 코드 모드라면 폴더를 열고, 그 밖의 모드라면 그냥 말을 걸면 됩니다.
5. **맡겨두기** — "매일 밤 정리해줘" 처럼 예약을 걸어두면 그때 알아서 이어집니다.

## 기술 스택

Tauri 2 기반 네이티브 Windows 앱입니다. 화면은 SolidJS, 백엔드는 앱에 동봉된 단일 바이너리로 동작합니다.

대화 기록과 설정은 **내 PC 에만 저장**됩니다. ULTRAI 자체 서버는 없으며, 대화 내용은 사용자가 직접 연결한 AI 공급자에게만 전송됩니다.
