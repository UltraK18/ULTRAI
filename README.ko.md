# ULTRAI

작업이 계속 굴러가는 Windows 데스크톱 AI 앱. 한 창에 네 가지 모드 — 대화하고, 실제 프로젝트 폴더에서 만들고, 캔버스에서 디자인하고, 이미지·영상을 생성합니다. 여기에 예약 실행, 다중 에이전트 런, 휴대폰 세컨드 스크린이 붙습니다.

## 다운로드

Windows 10 / 11 (x64). WebView2 런타임이 필요하며 대부분의 Windows 에는 이미 설치돼 있습니다.

**[최신 릴리스 다운로드](https://github.com/UltraK18/ULTRAI/releases/latest)** — `ULTRAI_x.y.z_x64_en-US.msi` 를 받아 실행하면 됩니다.

이후는 앱이 알아서 합니다. 실행할 때와 주기적으로 새 버전을 확인하고, 나오면 알려주고, 그 자리에서 설치합니다.

## 한 창에 네 가지 모드

각 모드는 전용 화면과 전용 도구, 전용 에이전트를 가집니다. 그래도 앱은 하나이고 설정도 하나이며, 기록이 쌓이는 자리도 하나입니다.

| 모드 | 화면 | 여기서 하는 일 |
| :--- | :--- | :--- |
| **Chat** | 대화 | 어떤 공급자·모델이든, 메시지마다 추론 강도 조절, 출처 있는 딥리서치, 파일·이미지 첨부 |
| **Code** | 실제 프로젝트 폴더 | 파일 트리, 검토 패널의 diff, 채팅 옆 터미널, 디스크를 건드리기 전 권한 확인 |
| **Design** | 라이브 캔버스 + 디자이너 에이전트 | 만드는 대로 화면이 채팅 옆에 렌더링되고, 완성된 결과는 Code 모드로 실제 파일로 넘어갑니다 |
| **Studio** | 자유 캔버스 + 채팅 | 이미지·영상을 생성해 배치하고, 내 파일을 끌어다 놓고, 이미 있는 것 위에 계속 얹습니다 |

모드를 바꿔도 재시작되는 건 없습니다. 모드마다 자기 대화를 따로 가지고, 사이드바는 지금 있는 자리의 것만 보여줍니다.

## 인터페이스가 곧 제품입니다

이 분야 도구는 대개 터미널이거나 웹페이지를 껍데기에 넣은 것입니다. ULTRAI 는 조립한 게 아니라 설계한 데스크톱 앱입니다.

- **흉내가 아닌 유리** — 떠 있는 표면은 블러 필터가 아니라 작은 렌더링 엔진이 그립니다. 베벨의 노멀맵을 구워 그 법선으로 스페큘러를 찍고, 뒤 배경을 변위시켜 가장자리가 굴절합니다. 토글·슬라이더는 한 걸음 더 나가 굴절률과 두께로 스넬 굴절을 풀기 때문에, 썸이 아래 트랙을 실제로 휘게 합니다. CSS 프로스트로는 안 되는 일이고, 차이는 모든 모서리에서 드러납니다.
- **스퀘어클 코너** — 원호가 아니라 초타원을 씁니다. `border-radius` 특유의 곡률 끊김 없이 곡선이 직선으로 이어집니다.
- **의도된 두 테마** — 라이트·다크가 살짝 푸른 기가 도는 하나의 콘크리트 톤 팔레트에서 나옵니다. 양쪽 어디도 눈이 시리지 않게 맞췄고, 모든 면이 토큰이라 화면마다 색이 갈리지 않고 앱 전체가 함께 움직입니다.
- **일부러 절제합니다** — 제품 안에 이모지가 없습니다. 느낌표도, 응원 문구도 없습니다. 패널은 각자 면 하나만 가지고, 구분은 상자 안에 상자를 그리는 대신 림 라이트와 그림자가 합니다.
- **심리스 창** — 32px 타이틀바가 Windows 11 규격을 지키면서 앱 배경색을 공유합니다. 콘텐츠 위에 얹힌 별개의 띠로 읽히지 않습니다.
- **모바일은 축소판이 아니라 다른 레이아웃** — 바텀시트, 전체폭 컨트롤, 터치 크기의 히트 영역. 창 너비가 아니라 기기 종류로 판정합니다.

## 생성 — 실제 모델들로

Studio 는 이미지 엔드포인트 하나가 아닙니다. 작업마다 카탈로그에서 골라 쓰고, 어떤 모델을 왜 썼는지 알려줍니다.

- **영상** — Veo 3.1 / Veo 3.0 (각 fast 변종 포함), Sora 2 / Sora 2 Pro, Grok Imagine Video, Gemini Omni Flash
- **이미지** — GPT Image 2 / 1.5, Gemini 3 Pro Image, Gemini 3.1 Flash Image (및 Flash Lite), Grok Imagine Image
- **영상을 입력으로** — 프롬프트만이 아니라 기존 클립을 넣어 다시 만들 수 있습니다
- **자기 출력을 스스로 검증** — 만든 영상에서 프레임을 뽑아 보고 다시 만들지 판단합니다
- **길이·판형·화질은 사용자 것** — 30초를 부탁하면 30초가, 요청한 판형으로 나옵니다

어떤 모델까지 닿는지는 연결한 공급자 계정에 따라 달라집니다 (Vertex AI, OpenAI, xAI).

## ULTRA 모드 — 여러 에이전트, 하나의 일

한 컨텍스트로는 벅찬 작업을 위한 모드입니다. 일을 태스크로 쪼개고, 단계별로 여러 에이전트에 배정해 돌리고, 결과를 **합치기 전에 독립적으로 검증**합니다 — 같은 에이전트가 자기 결과를 채점하는 게 아니라 크리틱과 적대적 검증을 거칩니다. 진행을 보면서 언제든 개입할 수 있습니다. 역할별로 모델과 추론 강도를 따로 지정하므로, 값싼 워커와 값비싼 검증자를 일부러 다른 공급자로 둘 수 있습니다.

## 약속을 지킵니다

"평일 아침 9시" 또는 "두 시간 뒤" 라고 말하면 메모가 아니라 실제 작업으로 등록됩니다. 시간이 되면 그 대화에 하나의 턴으로 도착하고 AI 가 일을 시작합니다.

- 달력과 목록으로 등록된 것을 한눈에 보고, 다음 실행은 사이드바 맨 아래에 늘 떠 있습니다
- 실행 시각에 앱이 꺼져 있었다면 놓친 것을 계산해 한 번의 만회 실행으로 묶습니다
- `/loop` 은 지정한 횟수만큼 같은 작업을 반복합니다

## AI 가 스스로 끝났다고 못 하는 목표

대화에 목표를 걸면 독립 평가가 완료를 통과시켜야 끝납니다. 작업을 한 에이전트가 스스로 끝을 선언하지 못합니다.

## 파고드는 리서치, 일하기 전의 질문

**딥리서치** 는 조사 각도를 먼저 세우고, 서브에이전트로 병행 검색·독해한 뒤 찾은 것을 인용합니다. 평소 검색도 기준이 셉니다 — 추측하지 말고 검색하도록, 학습 시점의 연도가 아니라 오늘 날짜를 쓰도록, 현재형 주장은 확인 뒤에 답하도록 지시돼 있습니다. 결과는 정설처럼 단정하지 않고 균형 있게, 출처를 본문에 달아 보여줍니다.

**딥인터뷰** — 요청이 덜 정해져 있으면 대화를 구조화된 인터뷰로 바꿔, 일을 시작하기 전에 원하는 것을 확정합니다.

## 다른 일 하는 동안에도 돌아갑니다

긴 작업이 창을 붙잡고 있지 않습니다.

- **백그라운드 실행** — 작업을 넘기면 격리된 채로, 대화의 포크로, 또는 서브에이전트로 돌아갑니다. 도중에 막히면 권한을 더 요청할 수도 있습니다.
- **실행 모니터** — 하단 바가 진행 중인 것을 한 줄에 모아 보여줍니다: 내가 띄운 백그라운드 작업, 다른 곳에서 시작된 것, 돌고 있는 서브에이전트 호출, ULTRA 런, 오래 붙잡고 있는 셸 명령까지. 눌러서 원하는 것으로 바로 들어갑니다.
- **대화 포크** — 어느 지점에서든 분기해 원본을 잃지 않고 다른 길을 시도하고, 메시지 인덱스에서 가지 사이를 오갑니다.

## 모드 사이의 핸드오프

작업이 시작한 모드에 갇히지 않습니다. Design 은 완성된 화면을 Code 로 **실제 파일**로 넘깁니다. Code 세션은 서로에게 질문과 결과를 넘깁니다. Studio 는 에이전트가 만든 산출물을 바로 캔버스에 올립니다. 핸드오프는 텍스트 블록 복사가 아니라 실제 파일이나 실제 턴이 움직이는 것입니다.

## 내 파일을 건드리지 않고 일할 공간

채팅 모드는 디스크에 자기 작업 공간을 따로 가집니다. AI 는 그 안에서 쓰고, 읽고, 실행하고, 고치는 것을 자유롭게 합니다 — 초안, 스크립트, 중간 파일. 매 단계마다 허락을 묻지 않고, 내 폴더로 손을 뻗지도 않습니다. 그게 어디인지 사용자가 알아야 할 필요는 없습니다. 결과만 받으면 되고, 직접 지목하지 않는 한 내 디렉토리는 그대로입니다.

## 세션끼리 대화합니다

Code 모드에서 한 세션이 다른 세션에 질문이나 결과를 넘길 수 있습니다. 백엔드를 보던 세션이 프론트엔드를 아는 세션에 물어보는 식입니다. 메시지는 상대 대화에 실제 턴으로 도착합니다. 통로는 사용자가 엽니다 — 스스로 연결되는 일은 없습니다.

## 휴대폰이 세컨드 스크린

서버를 켜고 같은 네트워크의 휴대폰 브라우저로 ULTRAI 를 엽니다. 모바일 화면은 데스크톱을 줄인 것이 아니라 터치용으로 따로 만들었습니다 — 바텀시트와 전체폭 컨트롤입니다. 대화·모델·설정을 공유하므로 하던 자리에서 이어집니다.

## 내 것으로 만들기

아래 전부가 내 디스크의 평범한 파일입니다. 읽고, 고치고, 버전 관리할 수 있습니다.

- **에이전트** — `~/.ultrai/agents/*.md`. frontmatter 가 모든 것을 정합니다: 어느 모드에 나타날지, 어떤 도구를 쓸 수 있는지, 어떤 프롬프트 섹션을 받을지, 어떤 기능(리서치·목표·인터뷰)을 쓸 자격이 있는지. 설정에서 바로 열어 고치고, 기본 제공 에이전트는 언제든 원본으로 복원할 수 있습니다.
- **스킬** — `~/.ultrai/skills/*/SKILL.md`. 모델이 필요할 때 가져다 쓰는 재사용 지시문이며, 슬래시 명령으로 직접 호출할 수도 있습니다. 하나씩 켜고 끕니다.
- **프롬프트 모듈** — 시스템 프롬프트는 카탈로그에서 조립되고, 어떤 섹션을 받을지는 에이전트 frontmatter 가 고릅니다. 아무것도 선언하지 않으면 기본 프롬프트와 바이트 단위로 같고, 켜는 순간부터 사고 방식이 달라집니다. 모드마다 그 일에 맞춰 만든 전용 프롬프트를 씁니다 — 하나를 억지로 늘려 쓰지 않습니다.
- **MCP 서버** — `ultrai.jsonc` 에 선언합니다. 로컬·원격 모두, 필요하면 인증까지, 서버별로 전환합니다.
- **메모리** — 나 / 주제 / 영역 세 갈래로 보관합니다. 요약만 주입하고 세부는 필요할 때 꺼내며, 주기적으로 중복·모순을 정리합니다. 채팅 모드에만 적용되고, 저장된 항목은 설정에서 전부 보고 지울 수 있습니다.
- **공급자** — Anthropic, OpenAI, Google, Google Vertex, xAI, OpenRouter 및 커스텀 엔드포인트를 본인 키로 연결합니다.

## 기록은 내 PC 에만 남습니다

대화 기록과 설정은 **내 컴퓨터에만** 저장됩니다. ULTRAI 자체 서버는 없으며, 대화 내용은 사용자가 직접 연결한 AI 공급자에게 본인 키로만 전송됩니다.

수집하는 것은 없고, 텔레메트리도 없습니다.

## 시작하기

1. **공급자 연결** — 설정 → 공급자에서 API 키를 넣습니다.
2. **모델 선택** — 모델과 추론 강도는 입력창 우측에 있습니다.
3. **모드 선택** — 사이드바 상단 탭입니다.
4. **작업 시작** — Code 모드는 폴더를 열고, 나머지 모드는 그냥 말하면 됩니다.
5. **맡겨보기** — "매일 밤 하루 정리해줘" 라고 하면 그때가 되면 알아서 시작합니다.

## 기술 스택

Tauri 2 기반 네이티브 Windows 앱입니다. 화면은 SolidJS, 백엔드는 앱에 동봉된 단일 바이너리로 동작합니다.
