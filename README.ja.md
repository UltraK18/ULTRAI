# ULTRAI

止まらずに進み続けるAI作業のためのWindowsデスクトップアプリ。ひとつのウィンドウに4つのモード――会話する、実在のプロジェクトフォルダでビルドする、キャンバス上でデザインする、画像や動画を生成する――に加え、スケジューリング、マルチエージェント実行、そしてスマートフォンをセカンドスクリーンとして使う機能を備える。

## ダウンロード

Windows 10 / 11 (x64)。WebView2ランタイムが必要ですが、ほとんどのWindows環境にはすでに入っています。

**[最新リリースをダウンロード](https://github.com/UltraK18/ULTRAI/releases/latest)** — `ULTRAI_x.y.z_x64_en-US.msi` を取得して実行する。

あとはアプリが自動で面倒を見る。起動時と定期的に新しいバージョンを確認し、利用可能になれば通知し、その場でインストールする。

## 4つのモード、ひとつのウィンドウ

各モードはそれぞれの用途に特化した画面であり、専用のツールとエージェントを持つ――それでいてアプリはひとつ、設定もひとつ、履歴の置き場所もひとつ。

| モード | 画面 | できること |
| :--- | :--- | :--- |
| **Chat** | 会話 | 任意のプロバイダーとモデル、メッセージごとの推論エフォート、引用付きのディープリサーチ、ファイルや画像の取り込み |
| **Code** | 実在のプロジェクトフォルダ | ファイルツリー、レビューパネルでの差分表示、チャット横のターミナル、ディスクに触れる前の権限確認 |
| **Design** | ライブキャンバス + designerエージェント | 画面が構築されていく様子がチャットの隣でそのままレンダリングされ、完成した成果物はCodeへ実ファイルとして引き継がれる |
| **Studio** | 自由形式のキャンバス + チャット | 画像や動画を生成し、配置・並べ替えし、自分のファイルを持ち込み、そこにあるものに手を加え続ける |

モードを切り替えても何かが再起動することはない――各モードは自分自身の会話を保持し、サイドバーには今いる場所に属する会話が表示される。

## インターフェースそのものが要点

この分野のほとんどのツールは、ラッパーに包まれたターミナルかWebページに過ぎない。ULTRAIはデザインされたデスクトップアプリであり、組み立てられただけのものではない。

- **本物のガラス** — 浮遊するサーフェスは、ぼかしフィルターではなく小さなレンダリングエンジンで描画される。ベゼル用の法線マップを焼き込んでそこからスペキュラハイライトを描き、背後にあるものを変位させることでエッジが屈折する。トグルやスライダーのようなコントロールはさらに踏み込み、屈折率と厚みを用いてスネルの屈折を解いており、つまみの下でトラックが曲がる。CSSのフロスト表現ではここまでできず、その差はあらゆるエッジに表れる。
- **スカラー形状の角丸** — パネルには円弧ではなくスーパー楕円を採用しており、`border-radius` にありがちな平坦な部分を作らずに、カーブが直線のエッジへとなめらかに入り込む。
- **意図を持って作られた2つのテーマ** — ライトとダークはどちらも、わずかに寒色寄りのコンクリート調の単一パレットを基盤にしており、どちらの端でもまぶしさが出ないよう調整されている。すべてのサーフェスがトークン化されているため、画面ごとにばらつくのではなくアプリ全体が一体となって動く。
- **意図的な抑制** — 製品内のどこにも絵文字はなく、感嘆符もなく、煽るような表現もない。パネルはそれぞれ単一のサーフェスで構成され、区切りは箱の中に箱を描くのではなくリムライトと影で表現される。
- **継ぎ目のないウィンドウ** — Windows 11の基準に沿った32pxのタイトルバーがアプリの背景色を共有しており、UIが本体の上に載った別の帯には見えない。
- **モバイルは縮小版ではなく別のレイアウト** — ボトムシート、フル幅のコントロール、タッチに適したヒット領域は、ウィンドウ幅ではなくデバイスによって決まる。

## 実在するモデルによる生成

Studioは単一の画像エンドポイントではない。ジョブごとにカタログから選び、どのモデルをなぜ使ったかを教えてくれる。

- **動画** — Veo 3.1・Veo 3.0(高速版も含む)、Sora 2・Sora 2 Pro、Grok Imagine Video、Gemini Omni Flash
- **画像** — GPT Image 2・1.5、Gemini 3 Pro Image、Gemini 3.1 Flash Image(Flash Liteを含む)、Grok Imagine Image
- **動画入力、動画出力** — プロンプトだけでなく、既存のクリップを入力として渡せる
- **自分の出力を自分で確認する** — 生成した結果からフレームを取り出して見直し、やり直すべきかを判断する
- **長さ・アスペクト比・品質は指定通り** — 30秒と頼めば30秒が作られる。要求した形のままに

利用できるモデルは、接続したプロバイダーアカウント(Vertex AI、OpenAI、xAI)によって変わる。

## ULTRAモード — 多数のエージェントで、ひとつの仕事を

ひとつのコンテキストに収まらない規模の作業向け。ULTRAは仕事をタスクへ分解し、フェーズごとに複数のエージェントへ配分して実行し、結果が統合される前に**独立した検証**を行う――同じエージェントが自分自身を採点するのではなく、批評役と敵対的チェックによる検証だ。実行中の様子はいつでも見ることができ、任意の時点で介入できる。モデルと推論エフォートはロールごとに設定できるため、安価なワーカーと高価な検証役を意図的に別プロバイダーにすることもできる。

## 約束を守る

「平日は毎日9時に」や「2時間後に」と言えば、それはメモではなく実際のジョブになる。実行時刻が来ると、そのタスクはその会話内のターンとして届き、AIが作業を始める。

- カレンダーとリストに登録済みのすべてが表示され、次の実行はサイドバーの一番下に表示される
- 実行予定だった時にアプリが閉じていた場合は、何が抜けていたかを把握し、ひとつのキャッチアップ実行にまとめる
- `/loop` は設定した回数だけタスクを繰り返す

## AIが自分では完了を宣言できないゴール

会話にゴールを設定すると、独立した評価がその完了をゲートする。作業を行っているエージェント自身が、完了の判断を下すことはできない。

## 掘り下げるリサーチ、着手前の確認

**ディープリサーチ**は切り口を計画したうえで、複数のサブエージェントにまたがって並行に検索・読解し、見つけたことを引用する。日常的な検索についても厳格さは変わらない――推測ではなく検索するよう、学習データに残った過去の年ではなく今日の日付を使うよう、現在時制の主張は答える前に検証するよう、モデルに指示されている。調査結果は偏りなく提示され、出典はインラインで示される。

**ディープインタビュー** — 要求の内容が曖昧なとき、会話を構造化されたインタビューへと切り替え、作業を始める前に本当に求めているものを絞り込む。

## 他のことをしている間も進む作業

長時間かかるジョブがウィンドウを占有し続けることはない。

- **バックグラウンド実行** — タスクを任せると、会話のフォークまたはサブエージェントとして分離実行され、行き詰まった場合は実行中に追加の権限を求めることもできる。
- **ライブモニター** — 画面下部のバーに、進行中のすべてが一度に表示される――自分自身のバックグラウンドタスク、他所で開始されたもの、実行中のサブエージェント呼び出し、ULTRA実行、しばらく動き続けているシェルコマンド。クリックすれば、見たいものへそのまま切り替わる。
- **会話をフォークする** — 任意の時点から分岐させて、元の会話を失うことなく別の可能性を試し、メッセージ一覧からブランチ間を移動できる。

## モード間の引き継ぎ

作業は始まったモードの中に閉じ込められない。Designは完成した画面をディスク上の実ファイルとしてCodeへ引き継ぐ。Codeのセッション同士は質問や結果を互いにやり取りする。Studioはエージェントが生成したものをそのままキャンバスに配置する。それぞれの引き継ぎは、コピーされたテキストの断片ではなく、実際のファイルや実際のターンを動かす。

## ファイルに触れずにAIが使える作業スペース

Chatモードには専用のスクラッチスペースがディスク上に用意される。AIはそこで、下書き・スクリプト・中間ファイルなどを、ステップごとに許可を求めることも、あなたのフォルダに立ち入ることもなく、自由に書き・読み・実行し・修正できる。その場所を意識する必要は一切なく、結果だけを受け取ればよい。自分のディレクトリは、自らそこを指定しない限り触れられないままだ。

## セッション同士が会話する

Codeモードでは、あるセッションが別のセッションへ質問や結果を引き渡せる――バックエンドを担当しているセッションが、フロントエンドを把握しているセッションに尋ねることができる。メッセージは相手の会話に実際のターンとして届く。チャンネルを開くのはあなた自身であり、勝手に接続されることはない。

## スマートフォンをセカンドスクリーンに

サーバーを起動し、同じネットワーク上のスマートフォンのブラウザでULTRAIを開く。モバイルレイアウトはタッチ操作向けに作られている――ボトムシートとフル幅のコントロールであり、デスクトップを縮小しただけのものではない。会話・モデル・設定は共有されるため、中断した場所からそのまま続けられる。

## 自分好みに作り替える

以下はすべて、ディスク上の普通のファイルであり、読み・編集し・バージョン管理できる。

- **Agents** — `~/.ultrai/agents/*.md`。フロントマターがすべてを決める――どのモードに現れるか、どのツールを使えるか、どのプロンプトセクションを受け取るか、どの機能(リサーチ、ゴール、インタビュー)を許可されるか。編集はSettingsから行い、組み込みエージェントはいつでも元の状態に戻せる。
- **Skills** — `~/.ultrai/skills/*/SKILL.md`。モデルが取り込める再利用可能な指示、あるいはスラッシュコマンドとして自分で呼び出せるもの。ひとつずつオン・オフを切り替えられる。
- **プロンプトモジュール** — システムプロンプトはカタログから組み立てられ、各エージェントのフロントマターがどのセクションを受け取るかを選ぶ。何も宣言しなければ、そのエージェントのプロンプトはデフォルトとバイト単位で同一になる。オプトインすれば、考え方そのものを変えられる。各モードは、あらゆる用途に無理やり合わせたひとつのプロンプトではなく、その作業のために作られた専用のプロンプトを持つ。
- **MCPサーバー** — `ultrai.jsonc` に宣言する。ローカルでもリモートでも、必要に応じて認証を付け、サーバーごとに切り替えられる。
- **Memory** — 3つのバケット(あなた自身について、トピック、領域)に保持され、要約が注入され、詳細は必要に応じて取得される。重複や矛盾をマージする定期的なクリーンアップも走る。Chatモード専用で、Settingsからすべてのエントリを確認・削除できる。
- **プロバイダー** — Anthropic、OpenAI、Google、Google Vertex、xAI、OpenRouter、およびカスタムエンドポイントを、自分自身のキーで利用できる。

## データはあなたのPCに留まる

会話と設定は**あなたのマシンにのみ**保存される。ULTRAIのサーバーは存在しない――あなたの会話が届く先は、自分自身で接続し、自分自身のキーを使う、AIプロバイダーのみだ。

何も収集されず、テレメトリもない。

## クイックスタート

1. **プロバイダーを接続する** — Settings → Providers でAPIキーを追加する。
2. **モデルを選ぶ** — モデルと推論エフォートは入力バーの右側にある。
3. **モードを選ぶ** — サイドバー上部のタブから。
4. **作業を始める** — Codeモードではフォルダを開く。それ以外のモードでは、そのまま話しかければよい。
5. **何かを任せる** — 「毎晩、その日のまとめを作って」と言えば、あとは自動で拾ってくれる。
