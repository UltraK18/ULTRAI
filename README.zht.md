# ULTRAI

一款持續運作的 AI 工作 Windows 桌面應用程式。單一視窗內涵蓋四種模式——對話、在實際專案資料夾中開發、在畫布上設計、產生圖像與影片——並支援排程、多代理執行,以及將手機作為第二螢幕。

## Download

Windows 10 / 11(x64)。需要 WebView2 執行環境,大多數 Windows 安裝已內建。

**[下載最新版本](https://github.com/UltraK18/ULTRAI/releases/latest)**——取得 `ULTRAI_x.y.z_x64_en-US.msi` 並執行。

之後應用程式會自行處理:啟動時與定期檢查新版本,有可用更新時通知你,並就地安裝。

## 四種模式,一個視窗

每種模式都是為特定用途打造的畫面,擁有各自的工具與代理——但仍是同一個應用程式、同一組設定、同一個保存歷史紀錄的地方。

| Mode | 畫面 | 在這裡做什麼 |
| :--- | :--- | :--- |
| **Chat** | 對話 | 任何供應商與模型,逐則訊息調整推理強度,附引用來源的深度研究,可匯入檔案與圖片 |
| **Code** | 實際的專案資料夾 | 檔案樹狀結構、審閱面板中的差異比對、聊天旁的終端機,任何異動寫入磁碟前皆有權限提示 |
| **Design** | 即時畫布 + 設計師代理 | 畫面在建置過程中即時顯示於聊天旁,完成的成果會以實際檔案交接給 Code |
| **Studio** | 自由畫布 + 聊天 | 產生圖像與影片、放置並重新排列、匯入自己的檔案、持續在既有成果上迭代 |

切換模式不會重新啟動任何東西——每種模式各自保留自己的對話,側邊欄只顯示屬於目前所在模式的對話。

## 介面本身就是重點

這個領域裡多數工具不過是包裝過的終端機或網頁。ULTRAI 是一款經過設計、而非拼裝而成的桌面應用程式。

- **真正的玻璃質感**——浮動面板運行一套小型渲染引擎,而非模糊濾鏡。它會為邊框烘焙法線貼圖並據此繪製鏡面高光,並使背後的內容產生位移,讓邊緣呈現折射效果。切換開關與滑桿等控制項更進一步,以折射率與厚度求解司乃耳折射,讓滑塊真的讓下方的軌道彎曲。CSS 的霧化效果做不到這一點,差異在每一道邊緣都看得出來。
- **超橢圓圓角**——面板採用超橢圓(superellipse)而非圓弧,讓曲線銜接直邊時不會出現 `border-radius` 常見的平坦斷點。
- **兩套主題,皆經深思熟慮**——淺色與深色主題建立在同一套帶有淡冷調的水泥色調色盤上,調校到兩端都不刺眼。每個表面都對應一個 token,讓整個應用程式一致變動,而非各畫面各自漂移。
- **刻意的克制**——產品中沒有任何表情符號、沒有驚嘆號、沒有搖旗吶喊式的用語。每個面板只承載單一表面,層次靠邊緣光與陰影區分,而非在框裡再畫框。
- **無縫視窗**——32px 高的標題列採用 Windows 11 的尺寸規格,並與應用程式背景共用同一色調,使外框不會被視為內容上方另一條獨立的橫條。
- **行動版是不同的版面配置,而非縮小版**——底部彈出面板、全寬控制項、觸控尺寸的可點擊區域,依裝置類型而非視窗寬度決定。

## 生成,使用真實模型

Studio 並非單一圖像端點。它會依每個工作從型錄中挑選模型,並告訴你使用了哪個模型、原因為何。

- **影片**——Veo 3.1 與 Veo 3.0(以及其快速版本)、Sora 2 與 Sora 2 Pro、Grok Imagine Video、Gemini Omni Flash
- **圖像**——GPT Image 2 與 1.5、Gemini 3 Pro Image、Gemini 3.1 Flash Image(以及 Flash Lite)、Grok Imagine Image
- **影片輸入、影片輸出**——可將既有影片片段作為輸入,而不只是文字提示
- **自我檢查成果**——從產生的內容中擷取畫面回看,判斷是否需要重試
- **長度、長寬比與畫質由你決定**——要求 30 秒,產出的就是 30 秒,並依你指定的形狀建置

能使用哪些模型,取決於你連接的供應商帳號(Vertex AI、OpenAI、xAI)。

## ULTRA 模式——多個代理,一項任務

針對超出單一情境容量的工作。ULTRA 會將任務拆分,依階段分派給多個代理執行,並在合併結果前**進行獨立驗證**——由一名評論者與對抗式檢查把關,而非由同一個代理自我評分。你可以全程觀察執行過程,並隨時介入。模型與推理強度依角色個別設定,因此便宜的執行者與昂貴的驗證者可以刻意來自不同供應商。

## 它會準時赴約

說出「每個平日早上 9 點」或「兩小時後」,它就會成為一項實際排程的工作,而不只是一則備忘。時間一到,任務會以一則訊息的形式出現在該對話中,AI 隨即開始處理。

- 行事曆與清單會顯示所有已登記的排程;下一次執行時間顯示在側邊欄底部
- 排程到期時應用程式沒開著?它會找出錯過的內容,合併成一次補齊執行
- `/loop` 會依你設定的次數重複執行任務

## AI 無法自行宣告完成的目標

為一段對話設定目標後,完成與否由獨立評估把關。執行工作的代理本身無權判定任務已經完成。

## 深入挖掘的研究,以及動工前的提問

**深度研究**先規劃切入角度,再透過多個子代理平行搜尋與閱讀,並為找到的內容附上引用來源。日常搜尋同樣要求嚴謹:模型被要求實際搜尋而非憑空猜測,使用當下日期而非訓練資料殘留的年份,並在回答現在式的主張前先行查證。研究結果會以持平的方式呈現,並附上內文引用。

**深度訪談**——當需求描述不足時,它會將對話轉為結構化訪談,在動工前先釐清你真正想要的結果。

## 在你做其他事的同時繼續運行的工作

長時間的工作不會綁架整個視窗。

- **背景執行**——交付任務後,它會以對話分支或子代理的形式隔離執行,若中途卡關,還能要求追加權限。
- **即時監控列**——底部的一條列會同時顯示所有進行中的工作:你自己的背景任務、其他地方啟動的任務、執行中的子代理呼叫、ULTRA 執行,以及任何耗時較久的殼層指令。點擊即可切換到想觀察的任一項目。
- **分支對話**——可從任意節點分出新分支嘗試不同做法,同時保留原始內容,並能從訊息索引在各分支間跳轉。

## 模式間的交接

工作不會被困在起始的模式裡。Design 會將完成的畫面以磁碟上的實際檔案交接給 Code。Code 的對話彼此之間可以傳遞問題與結果。Studio 會將代理產生的成果直接放上畫布。每一次交接移動的都是實際的檔案或實際的對話回合,而不是複製貼上的文字區塊。

## 一個 AI 可使用、卻不會碰到你檔案的工作空間

Chat 模式擁有自己專屬的磁碟暫存空間。AI 可以在其中自由寫入、讀取、執行與修改內容——草稿、指令碼、中間檔案——不需要每一步都詢問你的許可,也不會伸手碰到你的資料夾。你完全不必在意那個空間在哪裡;你只需要拿到結果,而你自己的目錄除非你主動指定,否則不會被觸碰。

## 彼此溝通的工作階段

在 Code 模式中,一個工作階段可以將問題或結果交給另一個——處理後端的工作階段可以詢問熟悉前端的那一個。訊息會以實際對話回合的形式送達另一個對話。頻道由你開啟;不會有任何連線自動建立。

## 你的手機就是第二螢幕

開啟伺服器後,即可在同一網路下用手機瀏覽器開啟 ULTRAI。行動版版面配置是為觸控打造——底部彈出面板與全寬控制項——而非桌面版的縮小版本。對話、模型與設定皆為共用,讓你能從中斷的地方原樣接續。

## 打造專屬於你的樣貌

以下每一項都是你磁碟上的一份純文字檔案,可供你讀取、編輯與版本控管。

- **Agents**——`~/.ultrai/agents/*.md`。frontmatter 決定一切:出現在哪些模式中、可使用哪些工具、取得哪些提示詞區塊、允許使用哪些功能(研究、目標、訪談)。可從 Settings 編輯,內建代理也能隨時還原成原始版本。
- **Skills**——`~/.ultrai/skills/*/SKILL.md`。可供模型自行引用的可重用指示,也可以用斜線指令手動呼叫。每一個都能個別開關。
- **Prompt modules**——系統提示詞是從一份型錄組裝而成,各代理的 frontmatter 決定要取用哪些區塊。不做任何宣告時,代理的提示詞會與預設版本逐位元組相同;選擇加入才會改變其思考方式。每種模式都附帶為該類工作打造的專屬提示詞,而非用一份提示詞硬套所有情境。
- **MCP servers**——在 `ultrai.jsonc` 中宣告。可為本機或遠端,依需求設定驗證,並可逐一伺服器切換開關。
- **Memory**——分為三個類別保存(關於你、主題、領域),摘要會自動注入,細節則依需求擷取,並有定期清理作業合併重複與矛盾的內容。僅限 Chat 模式使用,你可以在 Settings 中檢視並刪除每一筆項目。
- **Providers**——Anthropic、OpenAI、Google、Google Vertex、xAI、OpenRouter 以及自訂端點,使用你自己的金鑰。

## 你的資料留在你自己的電腦上

對話與設定**僅**儲存在你自己的裝置上。沒有 ULTRAI 伺服器——你的對話只會傳送給你自己連接的 AI 供應商,並使用你自己的金鑰。

不收集任何資料,也沒有遙測。

## Quick Start

1. **連接供應商**——在 Settings → Providers 中新增你的 API 金鑰。
2. **選擇模型**——模型與推理強度位於輸入列右側。
3. **選擇模式**——側邊欄頂部的分頁。
4. **開始工作**——在 Code 模式中開啟一個資料夾;其他模式則直接開始對話即可。
5. **交辦任務**——說「每天晚上幫我總結今天」,它就會自動接手處理。

## Tech Stack

一款基於 Tauri 2 打造的原生 Windows 應用程式。介面採用 SolidJS,後端則以單一執行檔的形式與應用程式一同封裝。
